# shugo releases

macOS app releases for **shugo** — downloads and the auto-update feed live here.

## Download

Get the latest version from [Releases](../../releases/latest):

| File | Mac |
|---|---|
| `shugo-*-arm64.dmg` | Apple Silicon (M1 or later) |
| `shugo-*.dmg` | Intel |

Both builds are signed and notarized, so the app opens with a normal double-click.

Not sure which chip your Mac has? Apple menu → **About This Mac** → check the **Chip** row.

## Auto-update

v1.2.3 and later check this repository's `latest-mac.yml` on launch and update in place — no manual download needed.

## Source code

The source repository is private. This repository only hosts distribution artifacts.
